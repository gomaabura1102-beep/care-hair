# 商品画像の登録

商品データ: `data/products.ts`。ブランドは既存の `data/product-insights.ts` から取得します。
価格は既存の表示用文字列、タグと診断用スコアは既存フィールドを維持します。
Amazonリンク: `amazonAffiliateUrl`。楽天リンク: `affiliateUrl`。

`officialImages` は、正規のAPIレスポンスや楽天アフィリエイト機能から取得し、
対象商品・画像利用条件・対応する既存購入リンクを確認した画像だけを登録します。
取得元の記録を別途保管してください。メタデータを付けるだけで利用許諾が得られるわけではありません。
旧 `affiliateImageUrl` のURLを解析・抽出・自動移行してはいけません。

登録フィールド:
- `source`: amazon / rakuten
- `obtainedVia`: amazon-associates-api / rakuten-ichiba-api / rakuten-affiliate
- `itemId`: 提供元の正確な商品ID
- `url`: 正式に提供されたURLをそのまま記録

画像は配列の順で1枚だけ表示します。クリック先は提供元に対応した既存リンクです。
読み込み失敗や1ピクセル応答の場合は次の正式画像に進み、最後は独自プレースホルダーに戻ります。
画像を取得・保存するサーバー処理やスクレイピングは実装していません。
現在の24商品には確認済みメタデータを登録していません。

既存コードにAmazon/Rakuten API連携や認証情報はありません。
`.env.example` にはSupabase、OpenAI、Google Analyticsだけが定義されています。
デプロイ先の秘密情報はこの作業から確認できません。

API自動取得は未実装です。画像表示自体には追加の環境変数は不要です。
自動取得を追加する場合は、楽天Web ServiceまたはAmazon Associatesの公式開発者設定から
その時点で必要な認証情報を取得し、サーバー専用環境変数として管理してください。
キー名・署名方式・利用資格は選択する公式APIの現行仕様に合わせる必要があります。
ダミーキーや仮のAPIアダプターは作成していません。
